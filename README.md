# green_lab

Green Lab 2026/2027, The Green Team: energy efficiency of Speculative RAG compared to standard RAG.

- `specrag-energy/`: experiment code, data, run tables and analysis (replication package).
  See `specrag-energy/README.md`.
- `Test/`: early prototype used to check what fits on the 8 GB GPU. Not used for any results.

The branch `experiment-final` contains the code exactly as it was used for the measurements.
